# What Drives Students' Final Math Grades?

Research project (n = 395 observations) for **Probability Theory and Mathematical Statistics**, Narxoz University.

**Data:** Cortez & Silva (2008), UCI *Student Performance* dataset (mathematics course, 395 students).

## Contents
| File | Description |
|---|---|
| `app.py` | Interactive Streamlit website with the full study |
| `student-mat.csv` | Dataset (semicolon-separated) |
| `requirements.txt` | Python dependencies |

The full Jupyter notebook with all code, outputs and interpretation is submitted together with this repository.

## Methods
Descriptive statistics · empirical & conditional probability · Bayes' theorem · method of moments · maximum likelihood ·
χ² goodness-of-fit · AIC · confidence intervals (t, χ², Wald, Wilson, Welch) · Welch t-test, ANOVA, Mann–Whitney,
Kruskal–Wallis, χ² independence · correlation & regression · Central Limit Theorem simulation · bootstrap.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
